# Sprint 6.4 Phase A — DONE (Gate A провален, направление «длинные горизонты» закрыто)

**Дата**: 2026-06-11
**Вопрос фазы**: растёт ли gross edge новостной стратегии с горизонтом удержания
быстрее, чем кости, и существует ли горизонт × класс с gross ≥ 2× cost (Gate A)?

**Ответ: НЕТ. Gate A провален по всем 20 ячейкам (5 горизонтов × 4 класса).**
Лучшая ячейка — eod/futures с ratio **0.21** (нужно ≥ 2.0; break-even ≥ 1.0).
Сигнал новостей **затухает после ~2 часов**, а не накапливается.

Новостной edge живёт ~1–2 часа (стоки) / до конца дня (фьючерсы) и **умирает
overnight** (t1 gross отрицательный). Гипотеза Phase A «длинный горизонт даёт
большие ходы при той же кости» опровергнута: кость падает с горизонтом (SL шире →
позиции меньше), но gross падает быстрее.

### Селективность не спасает (sweep 440 точек × 4 горизонта)

Единственный конфиг с n≥200 и положительным Sharpe — t1: rr=2.0/conf≥0.60/
stocks_futures → +129k, Sharpe +1.17, n=478. Форензика:
**top-5 trades = 97% PnL** (4 из 5 — VTBR), 16/36 фолдов в плюсе,
без top-5 остаток ≈ +3.5k на 473 сделках. Та же концентрационная патология,
что VTBR-кластер Sprint 6.3. **Не robust — отклонено.**

## Вердикт по плану Sprint 6.4

Gate A: ❌ → по утверждённому плану — **СТОП направления, пересмотр**.
Phases B–E (exit-геометрия, funding-aware сайзинг, financial-events корпус)
не запускались: они оптимизируют кости/селекцию вокруг gross-edge, которого
нет в нужном масштабе ни на одном горизонте.

## Накопленное свидетельство в пользу event-tier

Три независимых форензики дали одинаковую форму распределения PnL:
- Sprint 6.3 extended grid: весь плюс = VTBR 14.02.2025 (ралли Путин–Трамп);
- Phase A eod: один trade фолда 9 = 187% PnL конфига;
- Phase A t1: top-5 = 97% (VTBR 14.02.2025, 27.05.2026, BR oil-шоки).

Деньги в новостном потоке сидят в **считанных гигантских событиях** (5–10 в год),
а не в потоке из тысяч сделок. Поточная парадигма (Predictor на каждую новость)
структурно не окупает кости; событийная (торговать только top-tier события
с большим ожидаемым ходом) — единственное направление, где данные показывают
реальные деньги.
