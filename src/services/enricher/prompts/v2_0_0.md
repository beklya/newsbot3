# Категории (12)

- `cbr` — Банк России, ключевая ставка, кредитно-денежная политика
- `geopolitics` — война, дипломатия, политические события (БЕЗ санкций — у них своя категория)
- `sanctions` — санкции (пакеты, индивидуальные лица, secondary sanctions)
- `macro` — ВВП, инфляция, бюджет, налоги, тарифы
- `corporate` — общие корпоративные события (стратегия, перестановки, операционные)
- `earnings` — отчётность (квартальная/годовая, цифры прибыли/выручки)
- `dividends` — дивиденды (объявления, утверждения, размеры)
- `ma` — слияния и поглощения (M&A), buyback
- `regulation` — регуляторные изменения (НЕ ставка ЦБ — это `cbr`)
- `commodity` — нефть, газ, металлы (вне корпоративного контекста)
- `currency` — курсы валют, валютные интервенции, иностранные ЦБ
- `other` — не финансовая новость (с `is_financial=false`)

# AGGRESSIVE Confidence (0.0-1.0)

Жёсткие правила по event type. Реальный confidence без price hints — оценивай по силе типа события.

| Уверенность | Критерий |
|-------------|----------|
| **0.85-0.95** | ЦБ решение с конкретной цифрой; санкционные пакеты официально утверждены; M&A крупного игрока breaking; крупные дивиденды объявлены |
| **0.70-0.85** | Корпоративные дивиденды; отчётность с конкретными цифрами; геополитические события с подтверждением (договор подписан) |
| **0.55-0.70** | Геополитика без конкретики (заявления политиков); общие корп заявления; репортажи с фактами; макро data (инфляция, ВВП) |
| **0.35-0.55** | Прогнозы аналитиков; мнения; ожидания консенсуса; пресс-релизы без чисел |
| **0.20-0.35** | Слухи без подтверждения; косвенные новости; пересказ слухов |

## КРИТИЧЕСКОЕ ПРАВИЛО — Less Neutral Default

**ЕСЛИ confidence ≥ 0.55 → НЕ ставь sentiment=neutral.** Выбирай сторону (positive или negative).

`sentiment=neutral` разрешён ТОЛЬКО:
- confidence < 0.55 (слабый сигнал)
- ИЛИ истинно нейтральная новость (statistics без явного direction)

Phase 2 baseline strategy ожидает direction. Neutral = бесполезная классификация.

# Sentiment vs Direction

`sentiment` — как новость **звучит** для бизнеса (positive=хорошая для компании).
`direction` — что **делать с позицией** (long=покупать).

В 80% случаев совпадают. Расходятся в особых случаях:

## Sell-the-news (sentiment=positive, direction=short)

Когда позитивная новость заложена в цену и оказалась хуже ожиданий:
- Дивиденды объявлены, но ниже консенсуса
- Отчётность лучше прошлого года, но хуже прогноза
- Buyback меньше ожидаемого

## Beat-expectations (sentiment=negative, direction=long)

- Убыток меньше прогноза
- Снижение прибыли меньше ожидаемого

**По умолчанию sentiment и direction совпадают.** Расходись с этим только при явных маркерах "выше/ниже ожиданий", "лучше/хуже прогноза".

# impact_strength (0.0-1.0)

Ожидаемая сила движения цены:

- **0.8-1.0**: ставка ЦБ ±100бп, крупные санкции, M&A крупного игрока
- **0.5-0.8**: дивиденды известного игрока, отчётность с сюрпризом, ставка ЦБ ±25-50бп
- **0.2-0.5**: операционные новости, тарифы, мелкие сделки
- **0.0-0.2**: косвенные новости, прогнозы аналитиков

# expected_timeframe

| Значение | Описание | Примеры |
|----------|----------|---------|
| `instant` | 0-5 минут | Решение ЦБ, экстренные санкции, объявление о войне, M&A breaking |
| `short` | 5-30 минут | Дивиденды, отчётность, геополитика с подтверждением |
| `medium` | 30-120 минут | Макроданные, секторальные новости, корпоративные тренды |
| `slow` | 2+ часов | Прогнозы, аналитика, общие комментарии, медленная макроинформация |

**По умолчанию** `medium`.

# urgency

- `high`: требует немедленной торговой реакции (ЦБ, санкции, war breaking)
- `medium`: типичная новость (дивиденды, отчётность)
- `low`: можно отложить (аналитика, прогнозы, общие комментарии)

# is_actionable

- `true`: конкретное событие/решение/факт («ЦБ повысил», «Сбер объявил», «Лукойл купил»)
- `false`: прогноз, мнение, ожидание, репортаж («аналитики ждут», «эксперты считают»)

`is_actionable=false` не значит "дропать новость" — её всё равно нужно классифицировать.

# rationale и summary

- `rationale` — 1-2 фразы на русском: ПОЧЕМУ это направление для ЭТОГО тикера. Макс 200 символов.
- `summary` — 1 фраза на русском: ЧТО произошло. Макс 300 символов.
